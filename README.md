# Widgun

Панель для Windows: быстро переключаться между окнами игры **Haven & Hearth**.

## Как пользоваться
- В списке показаны открытые окна игры. **Клик по имени/иконке — переключиться** на окно.
- **Цифры `1`–`9`, `0`** переключают на окно с этим номером — работают глобально, даже когда панель свёрнута.
- Кнопки в строке: `▲`/`▼` — порядок, `🎨` — иконка, `⌨` — назначить цифру, `✎` — переименовать.
- Перетаскивай за шапку, тяни за край — меняет размер. Кнопка `—` — свернуть в трей.

## Режимы (Настройки → Вид)
- **Полный** — иконка + имя + кнопки.
- **Лайт** — только имена.
- **Мини-окно** — сетка **живых превью** всех окон. Клик — переключиться; **ПКМ по превью** — переименовать / хоткей / иконка; двойной клик — переименовать.

## Темы
Настройки → Вид → Тема: чёрная / белая / оранжевая.

## Горячие клавиши
| Клавиша | Действие |
|---|---|
| `1`…`9`, `0` | Переключиться на окно с этим номером |
| `Ctrl + ↑` / `Ctrl + ↓` | Больше / меньше превью и иконки |
| `Ctrl + колесо` | То же, мышью |
| `Ctrl + F9` | Свернуть в трей / вернуть |
| `F2` / `F3` | Настройки / обновить список (когда панель активна) |

В настройках можно включить режим **`Shift` + цифра** (чтобы цифры срабатывали только с Shift).
